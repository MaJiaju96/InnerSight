# 内观 InnerSight · UI 设计规范

v0.2 · 2026-11-24 ·「折光」已确认为全站视觉方向，浅深整套视觉稿已完成、待终审。本文定义 Web 界面的品牌、主题和共用控件；[项目搭建 UI](features/feature-20261124154000-项目搭建/03-ui-design.md)给出本期场景。字段、权限、操作结果和验收条件由当期 PRD 确定。

## 1. 品牌与折光镜片

中文主标「内观」，英文副标 InnerSight。登录与首次／重置后强制改密共用品牌区：标题「向内，见深。」下依次放引文「知人者智，自知者明。」和出处《道德经》第三十三章。认证页页脚用「内观，内视自身，自省自身。」解释项目名。按钮写动作，确认写对象与后果，错误写原因与恢复办法，这些位置不引经。中英文组合标以中文为第一阅读层级；窄屏优先压缩副标，保留「内观」。

保留从 Reeoo 参考中选用的三条版式原则：登录表单有一个明确焦点，页标题与说明有清楚层级，重复记录沿同一列比较。折光的识别图形是三片带孔的折光镜片：三片错层叠放，沿孔缘和薄边可看清前后关系。完整图形主要放在登录品牌区、首页当前账号卡的留白处；入口图标可取镜片的局部轮廓。高光、透色和视差只用于装饰，不覆盖字段、标签、焦点或提示。表格、权限目录、授权差异和危险确认使用不透明实底。

## 2. 两套主题共用的颜色与排版

同一页面只换语义色和装饰明暗，文字、数据、操作次序及权限保持一致。设计与实现按用途引用以下颜色：

| 名称 | 折光 / 浅色 | 折光 / 深色 | 用途 |
|---|---|---|---|
| `canvas` | `#F2F5F1` | `#101B1B` | 登录与后台的页面底色。 |
| `surface` | `#FBFCF8` | `#1C2B29` | 顶栏、侧栏、业务表单、表格与确认框的实底；认证卡可在边缘使用折光，字段和错误文字保持清晰。 |
| `ink` | `#20342A` | `#EDF4EB` | 品牌主标、标题、字段值及表格正文。 |
| `muted` | `#4C6054` | `#B8C9BC` | 副标、说明、列名和占位提示；字段仍有可见标签。 |
| `accent` | `#2F6048` | `#DDF4AD` | 主按钮底、链接和选中指示。 |
| `on-accent` | `#FBFCF8` | `#203329` | 实心主按钮及选中段上的字：浅色主题用白字，深色主题用墨字。 |

悬停或按下时用边线或底色变化，保持原有文字对比度；当前导航同时用底色、`accent` 竖线和较粗文字标示。错误和破坏性操作使用与主动作不同的危险色、明示后果的文字和不透明底色；「已停用」本身用中性样式。输入框与次按钮必须有可辨边界，表格分隔线只作辅助。

Pixso 画板文字使用 HarmonyOS Sans SC。HTML 优先使用本机的 HarmonyOS Sans SC，未安装时回退到微软雅黑、苹方或系统无衬线字体。1280px 桌面页首的字号／行高：首页 42/55px，用户与角色列表 31/40px。表单正文 16/24px，表格、按钮与说明 14/22px，随用户字号缩放。长句左对齐，角色编码、登录名照原文展示，完整值可在详情换行阅读。

## 3. 主题切换

- **位置与例外：** 页首右上、个人信息／账号菜单左侧放浅／深双段胶囊，登录前与强制改密时也在同一位置。它只改变本地外观。画板 14 的全屏详情与风险模态专注当前操作：先从详情「返回」或关闭模态，回到原页后再切主题；背景胶囊不接收焦点。
- **选择顺序：** 首次打开先读本地存储键 `innersight.theme`；有效手选值 `light` / `dark` 优先。没有有效手选值时跟随 `prefers-color-scheme`，无系统信号时用浅色。手选即生效并持久化，之后系统变化不覆盖手选；未手选时随系统变化。登录、退出、账号切换均不清除此偏好，它不携带身份或凭据。
- **存储不可用：** 读写被禁用或失败时仍可切换，以当前页面内存中的选择为准，登录或退出不主动重置；整页重载且无法恢复手选时再按系统／浅色回退。
- **样式与语义：** 胶囊用一组原生 radio，组名「界面主题」（`fieldset` / `legend`），两个可访问名称是「浅色」「深色」。桌面图标配文字，窄屏只显示日／月图标，名称仍供读屏读取；每段触控区至少 44×44px。选中滑块和日／月形状提供可见区别，原生 `checked` 向读屏报告选中项；键盘焦点在当前段的滑块上有清晰轮廓，强制颜色模式也应可辨。
- **键盘与动效：** Tab 入组到已选项，再按 Tab 离组；方向键移动焦点并切换选中项，空格（Space）选中焦点项。切换只更新当前页的主题，正文不跳转，筛选、表单值和提交状态保持原样。启用 `prefers-reduced-motion: reduce` 时停止镜片视差、浮动与主题过渡，选中态、焦点和文字反馈立即可见。装饰不获取焦点，也不参与读屏。

## 4. 布局与尺寸

- **间距和形状：** 以 8px 为基本步长。标签与字段相距 8px，字段之间 16px，内容面内边距 24px，独立区块间距 32px。按钮和输入框圆角 8px，内容面 12px；短状态标签与主题切换可用胶囊形。表格不用重阴影；浮起的菜单、面板或确认框可用轻阴影。
- **1280px 桌面基准：** 顶栏高 72px，后台侧栏宽 196px。登录与首次／重置后强制改密都采用折光分栏：左侧品牌与镜片，右侧宽 456px 的单列表单，标题、字段、主按钮左对齐。后台列表先排页名与主动作，其下为筛选和整宽记录。常规详情／编辑使用右侧面板（默认宽 480px）；画板 14 使用全屏详情。
- **中等宽度：** 空间收紧时顶栏出现「菜单」，侧栏按需展开；筛选可换行，常规面板仍可从右侧打开。登录和强制改密表单随空间缩小，不强行保留 456px 宽度。
- **窄屏（以 320px 检查）：** 主区边距 16px，面板全屏，表单单列。登录镜片可缩小或收起。顶栏仅显示日／月图标，每段分别保留 44×44px 触控区域，不挤压个人菜单。列表保留名称、状态和「查看」，其他字段及有权的管理操作进入详情。页名和操作可换行；整页不横向滚动，底部按钮不遮挡字段或焦点。

## 5. 控件、状态与可访问性

| 场景 | 统一约定 |
|---|---|
| 导航与操作 | 顶栏放品牌、主题与账号。首页「可用入口」和侧栏均按有效权限展示。重要业务操作有文字且无需悬停。每个操作区最多一个实心主按钮，次动作用描边，低频操作用文字。桌面常用控件高 40px；触屏独立操作至少 44×44px。 |
| 首页与管理权限 | 管理员林青有「用户管理」「角色管理」两个入口；仅有 `user:read` 的陈宁在首页看到「用户管理」，可直接进入只读列表（06／13）。画板 16 是「无管理权限／未分配角色」个人首页，没有管理入口，仍可修改自己的密码和退出登录。 |
| 表单与反馈 | 标签在字段上方，说明、报错紧贴字段。提交期间保留按钮位置，用「正在保存…」等实际动作并防止重复提交。校验失败聚焦首个错误字段并关联错误文字；成功提示供辅助技术播报。 |
| 列表与详情 | 表头与数据按列对齐，计数右对齐；桌面数据行至少 48px。名称链接有下划线，悬停可轻微改变行底；「查看」始终可见。状态明写「启用」「停用」「内置 · 只读」。只读字段显示值和原因，无权的管理动作不出现。 |
| 空、错与恢复 | 没有匹配项时在列表位置显示「没有符合条件的记录」和「清除筛选」。读取失败在原处给出原因和「重试」；写入结果未知时持续提示如何核对。失去读取权限立即清除原内容。错误、冲突或权限变化不只用颜色或短暂浮层表达。 |
| 高影响确认 | 标题点名目标，正文写清影响。授权列出本次增减，停用角色写明影响人数；按钮写「停用用户」「确认授予管理员权限」等实际动作。可取消的确认框初始焦点在「取消」。具体保护规则见当期 PRD。 |
| 键盘与辨识度 | Tab 顺序跟随阅读顺序；弹层打开后焦点留在层内，Esc 取消可取消的弹层，关闭后回到触发控件；若控件因撤权消失，移到有权访问的页标题。普通控件可用宽 2px 的焦点外圈；主题胶囊使用滑块内的焦点轮廓，避免窄屏裁切。两主题正文及操作文字对比度 ≥4.5:1，有意义的控件边界和焦点 ≥3:1；装饰线不用来识别控件。 |

## 6. 设计交付与核查

1. **静态看同号画板。** Pixso [折光 / 浅色（总览）](https://pixso.cn/app/design/NYBXHNEYrfdASgLhilojEg?page-id=6%3A198&item-id=6%3A199)与[折光 / 深色（总览）](https://pixso.cn/app/design/NYBXHNEYrfdASgLhilojEg?page-id=6%3A2344&item-id=6%3A2345)各有 00–20 共 21 幅。跨主题手动对照同一编号，正文、角色、数据、动作与异常应一致。两套稿均为可编辑静态图层；胶囊展示当前画板的选中态，不触发跳转。
2. **交互看两个样例。** [登录与后台首页 HTML](features/feature-20261124154000-项目搭建/04-motion-study.html)可实际操作。在登录、首页分别用 Tab、方向键和 Space 核对焦点、选中项及当页正文，切主题不跳转。无手选时检查系统深色与无信号回退；手选后登录、退出、刷新，再检查禁用存储和减少动态。样例使用演示身份，真实授权按 PRD 验收。
3. **按场景走查。** 在浅、深两套画板分别核对：画板 16 没有管理入口，保留个人改密与退出；仅有 `user:read` 的账号在首页有「用户管理」，进入 06／13 后可搜索、筛选、翻页、查看，无新建、编辑或授权动作。核对表格、权限与危险确认为实底，画板 14 和风险模态先返回原页再切主题。在 320px 窄屏、桌面放大 200% 时检查长名称、焦点和触控范围；分别走查无匹配、读取失败、撤权和编辑冲突的恢复入口。视觉走查与业务验收分别记录。
