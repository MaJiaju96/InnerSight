## 1. 本次交付与演示主线

目标：维护者能从空环境搭好 InnerSight，使用管理员账号给第二个人分配恰当的后台权限，并亲自验证授权和撤销确实生效。首页、会话和管理操作读取真实后端；本次演示不需要模型、题库或训练记录。

1. 部署者按启动说明初始化空库，使用自己的初始凭据登录，完成改密后进入后台首页。
2. 管理员新建“用户只读”角色，仅勾选 `user:read`；再创建一个无角色账号，单独给它分配该角色。
3. 第二个账号在另一个浏览器会话中登录、改密、重新登录。它能查看用户列表，但没有新增、授权或角色管理入口。
4. 管理员收回角色。第二个账号在原会话重新访问用户列表即被拒绝，仍可回个人首页；停用该账号后，原会话要求重新登录。

不在本次导航或验收中加入训练、题库、报告及二期入口。本稿确定用户动作和预期反馈，后续 UI 承接页面布局、控件及视觉设计。

## 2. 页面与操作

| 页面/流程 | 用户动作与成功结果 | 失败、空态与权限变化 |
|---|---|---|
| 登录 | 输入登录名和密码。临时密码进入改密；正常登录进入首页，或回到原先有权访问的站内页面。提交中防止重复点击。 | 字段缺失定位到输入框；认证失败统一提示，保留登录名、清空密码。频率受限提示稍后重试；服务不可达提示连接失败，不显示账号密码错误。 |
| 改密 | 填写当前密码、新密码及确认。临时密码会话只能改密或退出；提交成功后返回登录，明确需要使用新密码。已登录用户也可主动改密。 | 两次输入不一致就地提示。服务端校验失败不变更旧密码；凭据不回显、刷新后不保留。 |
| 后台首页与导航 | 显示当前用户、有效角色、可访问入口、改密和退出。没有管理权限时说明“暂无管理权限”，个人入口可用。 | 初始化身份期间显示加载；403 保持登录，清除已无权查看的内容，提供返回首页；会话过期或账号停用返回登录。连接失败提供重试，不以空数据代表成功。 |
| 用户列表与详情 | 具备读取权限可搜索、按状态筛选和分页。列表展示登录名、显示名、状态、角色摘要；可查看详情。维护者按权限新建无角色用户、修改显示名、启用或停用。 | 空库搜索与请求失败使用不同提示；提交前校验必填和格式，重名在字段旁提示。停用前展示目标及旧会话将失效。对自己或管理员账号隐藏不允许的操作。 |
| 用户授权与密码重置 | 仅内置管理员可进入。分配角色时展示当前选择与此次增减；涉及 `ADMIN` 时明确提示将授予后台管理权。重置他人密码时说明旧会话将退出，下一次登录须改密。 | 取消则无修改。保存冲突时显示“数据已更新，请重新加载后确认”，不自动覆盖。无权请求和保留管理员规则的拦截均不得改变数据。 |
| 角色列表与详情 | 具备读取权限可搜索、按状态筛选和分页。详情显示名称、固定编码、状态、权限项与绑定人数。管理员可创建自定义角色、改名称/权限、启用或停用。 | `ADMIN` 标为内置只读。角色可不选权限；勾选管理项时展示隐含读取权限。停用或重新启用前显示影响人数及对已有绑定的影响。 |

列表与表单按[需求分析书](01-requirements.md)的字段和权限规则执行。写入时只在服务端确认后显示成功；若网络中断、提交结果未知，提示重新读取记录确认，再决定是否重试。未提交的非敏感字段可保留，密码不得持久保存。

## 3. 开发交接

| 交付面 | 当期开发与 UI 的直接依据 |
|---|---|
| 工程 | 提供可从干净目录复现的依赖、运行版本、配置示例、初始化、启动和验证步骤。开发、部分回归和全量回归库按[技术方案书](../../02-technical-design.md)隔离。就绪检查须能区分服务可达与数据库可用；启动文档不得包含可用密码或密钥。 |
| 页面 | 设计登录、改密、后台首页、用户和角色管理。分配角色/重置密码是用户管理操作，不另建通用权限平台。UI 需覆盖加载、无记录、无权、会话失效、连接失败、保存冲突六种状态。 |
| 服务端 | 身份认证、会话撤销、用户、角色与授权在同一后端中划清职责；前端展示与后台执行采用同一套有效权限。禁止以 Mock、管理员特例页面或隐藏按钮代替真实鉴权。 |
| 操作结果 | 未登录或会话失效为 401；有会话但权限不足为 403；唯一性、旧版本写入或管理状态冲突为 409；频率受限为 429。输入校验错误返回 400 并定位字段，依赖故障返回 503（服务不可用）；对用户不展示内部异常。 |

## 4. 验收用例

验收环境：当前 `master` 候选提交、专用 MariaDB Server 10.11.19 全量回归库 `innersight_master`、两个独立浏览器会话。首次迁移前保存 `SELECT VERSION(), DATABASE();` 的结果，核实产品、补丁版本、库名，并检查库为空。任一前提不满足就停止，不执行迁移；记为「环境不符，未执行」。计时边界用可控测试时钟验证。验收记录关联候选提交、版本查询原文和实际执行的用例编号。

| 用例 | 关联规则 | 操作 | 预期结果 |
|---|---|---|---|
| AC-01 从零启动 | FR-01、NFR-03 | 在已核实的目标空库上，按启动说明同时执行两次管理员初始化，由应用运行 Flyway 迁移；启动前后端，登录后重启再登录。 | 迁移成功；只有一个首个管理员与一份内置角色，重跑不改密码；能真实登录，重启后数据保留，不配置 AI 不影响启动。 |
| AC-02 登录与退出 | FR-02、NFR-01 | 分别使用不存在、停用、密码错误的账号；验证失败限制窗口；正常账号登录、刷新、退出，另验空闲及绝对过期。 | 认证失败提示一致；达到限制后 429，窗口结束可再试。有效会话刷新仍在，退出或过期后的旧会话访问受保护资源为 401。 |
| AC-03 密码生命周期 | FR-02、FR-03、NFR-01 | 以临时密码登录并访问管理页；改密后重新登录；另开会话，由管理员重置其密码。 | 待改密会话不能访问后台业务；新密码生效后旧密码和各旧会话失效；重置后再次要求改密。错误当前密码、两次输入不一致、长度不符均不改变账号。 |
| AC-04 管理用户 | FR-04、FR-07、NFR-02 | 并发创建两个仅大小写不同的登录名；查询该用户、编辑显示名、停用、再启用。 | 仅一个账号，另一条创建返回冲突；初始无角色；可按名称和状态找到。停用后所有旧会话失效，启用后必须重新登录。 |
| AC-05 角色的生命周期 | FR-05、FR-06 | 新建角色并绑定用户；尝试重复编码、未知权限、修改内置角色；停用后重新启用自定义角色。 | 无效变更被拒绝；停用保留绑定但不再授权，重新启用后权限恢复；确认页人数与实际绑定数一致。 |
| AC-06 权限在服务端生效 | FR-04、FR-05、FR-06、NFR-01 | 依次用未登录、无角色、只读和普通用户维护者访问相应管理操作；尝试给自己授权或修改管理员账号。 | 未登录返回 401；只读可以查询但不能编辑。维护者能创建无角色的普通账号，但不能分配角色、重置他人密码或修改管理员账号；无权操作一律 403 且无副作用。 |
| AC-07 多角色与实时撤权 | FR-05、FR-06 | 给一个账号分配两个都能读用户的角色，分别移除第一个和最后一个；使用原会话刷新用户列表。 | 移除第一个仍能读；最后一个移除成功后的下一请求返回 403，页面清除列表并保留个人首页。无需退出重登。 |
| AC-08 保留管理员 | FR-06、FR-07、NFR-02 | 唯一管理员尝试停用自己或移除自己的管理员角色；再配置两名管理员，同时停用对方。 | 前两项被阻止；并发写入后至少保留一名可登录的启用管理员，失败一方没有部分修改。 |
| AC-09 并发编辑 | FR-04、FR-05、FR-06、FR-07、NFR-02 | 两个管理员基于同一旧版本分别改同一用户角色集合，另对同一角色的权限集合和同一用户资料重复验证。 | 首次成功；过期提交返回 409，提示重载，首次结果保留。非法或失败的一组绑定没有部分落库。 |
| AC-10 依赖故障与追溯 | FR-01、NFR-01、NFR-03 | 断开测试库后加载列表或保存变更，恢复后重试；检查初始化、重置、授权和失败登录的输出。 | 就绪检查和页面如实显示故障；无虚假成功，恢复后记录可读。成功变更可定位操作人与对象；日志、前端持久存储及普通业务响应无密码或会话凭据。核对生产配置下的 Cookie 保护属性；无有效跨站请求校验的写入被拒绝，数据不变。 |
| AC-11 列表与性能 | FR-04、FR-05、NFR-04 | 准备规定样本，筛选、翻页并请求超大分页；对比不同页大小下的角色摘要查询次数。 | 每页不超过 100 条，筛选和排序稳定；同一快照翻页不重不漏。查询次数不随一页用户数逐条增长，保留实测环境与耗时。 |

## 5. 完成条件

需求和 PRD 评审、同编号 UI 确认后进入开发。提交开发验收前自审本需求完整代码差异，重点核对并发授权、会话失效、异常恢复及列表查询；按[项目开发约束](../../../AGENTS.md)留存问题、修复及实测输出。`dev` 完成开发验收、`test` 通过部分回归后合入 `master`；`master` 同一候选通过全部上述用例并确认 UI 后方可发布；结果登记在 [PRD 进度](../../PRD_PROGRESS.md)。
